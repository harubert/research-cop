# Task: review one text

Apply the rubric to the document below.

Procedure:
1. Read the whole text first (the page-numbered text below; the PDF itself is attached when available, use it for tables and figures).
2. Identify title, authors, venue, year and text type from the text itself.
3. Check systematically: every number that can be recomputed, every citation against the reference list, every central claim against its evidence.
4. Recompute with the code execution tool; check doubtful sources with web search (at most about six searches).
5. Write findings in **{language}**. Keep `quote` and `anchor` in the original language of the text.

`page_pdf` is the page number as given in the `=== PAGE n ===` markers below. `page_print` is the printed page number if visible, otherwise empty.

Return only the JSON object required by the output schema.
